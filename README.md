# 圣光大教堂 · 3D中国象棋 (Gothic Cathedral 3D Xiangqi)

基于 Three.js 与 Material Design 3 构建的盛期哥特式大教堂 3D 中国象棋网页应用。

## 在线体验 (Live Demo)
- **GitHub Pages**: [https://karlazx.github.io/ai-china-xiangqi-3d/](https://karlazx.github.io/ai-china-xiangqi-3d/)

## 核心特性
- **盛期哥特式大教堂场景**：玫瑰花窗、群青镶金星穹拱顶、24K鎏金管风琴、轮式吊灯与三层大理石圣坛。
- **物理材质与4类程序化动画**：玫瑰玛瑙白玉与黑曜石棋子，支持呼吸闲置、抛物线落子、蓄力跃击及28块3D多面体碎裂物理效果。
- **完整中国象棋规则与AI**：支持蹩马腿、塞象眼、飞将、送将禁手检测及 Alpha-Beta 剪枝 AI 对弈。
